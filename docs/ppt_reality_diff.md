# ppt_reality_diff.md

PPT 与真实项目的冲突识别（供负责 PPT 的 ChatGPT 修改）。

| Slide | PPT 可能出现的概念 | 实际项目 | 处理建议 |
|---|---|---|---|
| 2/4 | 6 个 Agent | 7 个业务 Agent（3 个并行决策） | 改为 7 个，强调 3 个候选决策 |
| 4 | Planner / Supervisor Agent | 无 Planner，固定 LangGraph 拓扑编排 | 删除，改为「LangGraph 固定拓扑」 |
| 4 | 智能调度算法 / 动态任务规划 | 固定图拓扑，无动态规划 | 删除或改为「固定工作流编排」 |
| 4 | Tool 调用 / 工具注册 | 有 LLM 调用 + yfinance 数据，无独立 Tool 注册表 | 改为「数据源 + LLM 调用」 |
| 5 | 智能异常检测（暗示 ML 算法） | 规则扫描（超时/循环/空输出阈值判断） | 改为「执行异常监控（规则）」 |
| 5 | Retry / 重试机制 | 无显式重试，有 LLM 失败降级兜底（回退默认分） | 改为「失败降级兜底」 |
| 5 | Checkpoint / 状态持久化 | LangGraph state 字典，无 checkpoint 持久化 | 删除或说明为「内存 state」 |
| 6 | 自研智能多维度结果优化算法 | 规则 + LLM-as-Judge（规则过滤 + 五维加权 + LLM 打分） | 改为「规则约束 + 大模型语义评价」 |
| 6 | 候选结果数（如 10 个候选） | 3 个候选决策 | 改为 3 个 |
| 7 | 生产环境部署 / 业务收益 / 用户量 | 原型系统，未上线 | 删除，明确"原型系统" |
| 7 | 替代投资顾问 | 投顾辅助（辅助而非替代） | 改为「辅助」 |

## 结论
核心事实：**7 个 Agent + 3 个候选决策 + 规则与 LLM 双重评价 + 原型系统**。凡是"智能算法""动态规划""生产部署"类表述都需要修正。
