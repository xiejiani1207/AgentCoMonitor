> 说明：本项目开发过程是"我主导设计决策 + AI 辅助实现代码"的协作模式（git 提交均为 Co-Authored-By: Claude）。以下按"我做了什么 / 参与了什么"区分，便于答辩时准确表述。具体分工如有出入请按实际情况调整。

## A. 我主要完成（设计决策 + 方向把握）

这些是贯穿项目的关键**架构与设计决策**，由我拍板，体现的是"我理解问题、能做技术取舍"：

- 项目定位：通用监控平台（领域无关）+ 金融投顾 Demo（验证场景）
- 架构选型：监控与 Demo **零侵入解耦**（`demo_advisory/` 不 import `agent_monitor`）
- 进程架构：监控服务 + 投顾服务两个 FastAPI 进程，通过 HTTP 反馈链路解耦
- 反馈闭环：监控发现不达标 → 自动反馈指令 → 回灌 Demo 动态指令库 → 自我优化
- 合规检测：敏感词库（DB + 可增删）+ 句级标红 + 句级拦截
- 结果筛选：三个并行候选决策 Agent + 四步筛选排序
- 演示模式：prompt 引导 + 自然注入兜底，保证演示确定性
